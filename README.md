# DEAD OR ALIVE（仮）— Ver.1.0

Flutter 製の2人対戦カードゲーム（ルール検証用プロトタイプ）。
確定ルールは **[RULES.md](RULES.md)** を参照。
**同じ端末で交互に操作するローカル2人対戦**です。Flutter Web で動作し、スマホ幅にも対応します。
オンライン対戦・課金・外部バックエンド・CPU は含みません。

## 対戦モード

- **CPU対戦**（既定）：あなた＝プレイヤーA、CPU＝プレイヤーB。CPU は自分の既知列と公開情報から貪欲に行動します。
- **2人対戦**：同じ端末で交互操作（ホットシート）。
- タイトルでモードとプレイヤーAの陣営を選んで開始。

## 画面の見え方

- **自分が初期に見られるのは下段3枚、相手は上段3枚**（中段3枚は誰も見ない）。
- 人間カードの**左上の数字＝そのカードの得点**で、**表裏を問わず常に表示**（伏せられるのは種類だけ）。
- **相手の残り手札**を盤面の上に常時表示（スクロールなし）。

## のぞき見（タップで表確認）

対戦中、盤面は伏せられますが、**自分の下段カードには目印（👁）**が付き、
**アクションカード未選択のときにタップすると表向き**になって種類・得点を再確認できます。
アクションを選んでいるときのタップは対象選択になります（手番が変わるとのぞき見はリセット）。

## 無効なアクションの禁止

**表向き（公開済み）のカードに、状態が変わらないアクションは使えません**
（例：公開された生存カードへ「生」、公開された死亡カードへ「死」、保護済みへ「保」）。
アクション選択中は、そうした対象が暗く表示され選べません。

## ゲーム概要

- プレイヤーは **救済者** か **執行者**。
  - 救済者：**善人と中立を生かし、悪人を殺す**と得点。
  - 執行者：**悪人を生かし、善人と中立を殺す**と得点。
- 得点が高い方の勝ち（同点は引き分け）。

### 人間カード（9枚）

善人 / 中立 / 悪人が各3枚。得点はそれぞれ **1・2・3**。3×3で中央に伏せて配置し、全員「生」で開始。

### 初期情報

- **プレイヤーAは下段3枚**、**プレイヤーBは上段3枚**の「種類と得点」を確認（中段3枚は誰も見ない）。
- 確認後は伏せられ、以後は記憶と推理で戦う（生/死で使われたカードだけが公開される）。

### 手札（各プレイヤー9枚・陣営で構成が異なる）

**生 / 死 / 保 / 診**（数字なし）。枚数は陣営で偏りがあり、`game_constants.dart` で調整できます。

- 既定：**救済者＝生4/死2/保2/診1**、**執行者＝生2/死4/保2/診1**（救済者は生が多く、執行者は死が多い）。
- **生**：対象を「生」にする。使うと対象を**公開**。
- **死**：対象を「死」にする。使うと対象を**公開**。
- **保**：対象に保護を付与。保護中に生/死を受けると**保護だけ壊れ、生死は変化しない**。保では公開されない。
- **診**：対象の正体（種類）を**自分だけ**確認する。相手には公開されず、状態も変化しない。既に分かっているカードには使えない。

### 進行と勝敗

- 交互に1枚使用 → 対象を選ぶ → 効果処理 → 捨てる。両者の手札が尽きたら終了。
- 終了時に全カードを公開して集計：
  - 各カードの得点は、最終状態に応じて **どちらか一方**に入る（善人/中立＝生存で救済者・死亡で執行者、悪人＝逆）。
  - 得点合計は常に18で、その取り合い（ゼロサム）。

## 画面

タイトル / ゲーム / リザルト の3画面のみ（ルール画面なし）。
ゲーム画面は中央3×3、下部に手札9枚・現在ターン・暫定得点（公開分）・残り手札を表示。スマホで1画面に収まります。

## セットアップ / 起動 / テスト

```bash
flutter pub get
flutter run -d chrome                 # Web で起動
flutter build web --release --base-href /d_o_a_test/ --no-web-resources-cdn
flutter analyze
flutter test
```

動作確認は Flutter 3.44.7 / Dart 3.12.2。

## 実装構成（拡張しやすい分離）

ゲームロジックは **GameEngine** に集約（Widget にロジックを書かない）。

```
lib/
  app/            … MaterialApp / router(title/game/result) / theme
  features/
    title/ result/
    game/
      domain/       … HumanCard, ActionCard, Player, GameState, GameResult,
                      enums(HumanType/CardState/ActionType/Faction/PlayerId/GamePhase)
      application/  … GameEngine（setup/applyAction/score）/ GameController（Riverpod）
      presentation/ … ゲーム画面（確認フェーズ＋対戦）
  shared/widgets/   … HumanCardWidget / ActionCardWidget
  shared/utils/     … アイコン・色・ラベル
```

## テスト（`flutter test`）

- 生カード / 死カード / 保カード（保護吸収）/ 公開処理 / ゲーム終了 / 得点計算（合計18・引き分け）/ セットアップ
- 確認→対戦→終了の通しプレイ / タイトル→開始→確認フェーズ（ウィジェット）

## 仮定・簡略化

- プレイヤーAの陣営はタイトルで選択（Bは反対陣営）。Aが先手。
- **生/死は対象を必ず公開する**（保護で生死変化が吸収された場合も公開。公開ルールは無条件のため）。保は公開しない。
- 初期情報はホットシートの「確認フェーズ」で各プレイヤーが順に見る方式（渡し合い）。対戦中は記憶ベース。
- Flutter 未導入環境向けに、検証時は SDK を導入して analyze/test/build を実行。
